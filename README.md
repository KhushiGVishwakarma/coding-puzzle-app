# 📱 Coding Puzzle App

An **Android-based educational quiz app** designed to help users improve their coding skills through interactive puzzles in various programming languages like Java, Kotlin, Python, and more.

## 📝 Project Description

**Coding Puzzle App** is an Android application aimed at enhancing programming skills through quizzes. It features categorized challenges based on difficulty and language, with instant feedback, score tracking, and competitive leaderboards. Built for students, professionals, and coding enthusiasts.

---

## 🚀 Features

- **User Authentication** (Email/Password, Google Sign-In via Firebase)
- **Language-specific Quizzes** – Java, Python, C++, Android, Kotlin, Web
- **Leaderboard System** – Compete with other users
- **Progress Tracker** – View solved puzzles and scores
- **Modern UI** with intuitive navigation
- **Secure Firebase Backend** for real-time database and authentication

## 🛠️ Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone https://github.com/KhushiGVishwakarma/coding-puzzle-app.git

---
Open in Android Studio

Go to File > Open and select the project folder

Firebase Setup

Add your google-services.json file to the /app folder

Enable Firebase Authentication & Realtime Database in Firebase Console

Build & Run

Choose a virtual or physical device and click "Run"
